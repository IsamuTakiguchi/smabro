# smabro — 大乱闘ブラストファイターズ

ブラウザで遊べる、スマブラ風の大乱闘アクションゲームです。
相手をふっとばして画面の外へ出せば撃墜。ダメージ%が高いほど遠くへ飛びます。

- ビルド不要（HTML + Canvas + JavaScript）。外部ライブラリはオンライン対戦時に読み込む PeerJS のみ
- 最大4人（人間・CPUを自由に組み合わせ）
- キーボード / ゲームパッド / スマホ・タブレットのタッチ操作に対応
- **オンライン対戦**：複数の端末（タブレット・スマホ・PC）をつないで最大4人で対戦
- オリジナルキャラクター4体（ブレイズ・ガント・ゼファー・ミスティ）
- オリジナルBGM（メニュー／バトル）と観客の歓声・拍手（すべてブラウザ内で合成、音源ファイルなし）

## あそびかた

| 操作 | 1P キーボード | 2P キーボード | ゲームパッド |
| --- | --- | --- | --- |
| 移動 | A / D | ← / → | スティック / 十字 |
| ジャンプ | W / Space | ↑ / テンキー0 | X / Y |
| 急降下・すり抜け | S | ↓ | 下 |
| 攻撃 | F | , / テンキー1 | A |
| 必殺技 | G | . / テンキー2 | B |
| シールド・回避 | H | / / テンキー3 | LB / RB / LT / RT |
| ポーズ | Esc / P | Esc / P | START |

- 攻撃・必殺技は方向キーとの組み合わせで技が変わります。
- **上＋必殺技**は復帰技。場外から戻るときに使いましょう。
- シールド中に左右で回避、空中でシールドを押すと空中回避。
- ステージの端でガケつかまり（上でのぼる／ジャンプでガケジャンプ／攻撃でのぼり攻撃）。

## オンライン対戦（複数端末）

1. 1台目：タイトルの「オンライン対戦」→「部屋をつくる」→ 4文字の部屋コードが表示されます
2. 2台目以降：「オンライン対戦」で部屋コードを入力して「参加する」（または「招待URLを共有」で送ったURLを開くだけ）
3. 各自で自分のキャラを選び、部屋をつくった人（ホスト）が「たたかう！」

- 空いている枠はホストが CPU にできます。対戦中に抜けた人は CPU が引きつぎます。
- 仕組み：ホスト端末がゲームを計算し、参加端末は WebRTC（[PeerJS](https://peerjs.com/)）で入力を送って画面を受け取ります。サーバーの用意は不要です。
- 同じ Wi-Fi 内がいちばん快適です。学校・会社などのネットワークでは通信が制限されてつながらない場合があります。

## 自動デプロイ（GitHub Actions → GitHub Pages）

`.github/workflows/deploy.yml` により、次のように全自動で動きます。

1. どのブランチへの push / PR でも、構文チェックと CPU 同士の対戦シミュレーションテストを実行
2. `main` ブランチへの push（PR のマージを含む）でテストが通れば、`public/` を GitHub Pages へ自動デプロイ

### 初回のみ必要な設定

リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定してください。
（一度設定すれば、以後は `main` に反映されるたびに自動で公開されます。）

公開URL: `https://<ユーザー名>.github.io/smabro/`

## ローカルで動かす

```sh
npm run serve        # http://localhost:8080 で起動（または任意の静的サーバーで public/ を配信）
npm test             # シミュレーションテスト
npm run check        # 構文チェック
```

## ファイル構成

```
public/
  index.html        画面（タイトル・キャラ選択・結果など）
  style.css
  src/
    engine.js       ゲームロジック（物理・技・ふっとばし・撃墜）※DOM非依存
    ai.js           CPU の思考
    render.js       Canvas 描画・エフェクト・HUD
    input.js        キーボード / ゲームパッド / タッチ入力
    net.js          オンライン対戦（WebRTC 接続・状態同期）
    audio.js        WebAudio 効果音
    music.js        BGM・観客の歓声（WebAudio で合成）
    main.js         画面遷移・ゲームループ
tests/sim.test.mjs  CPU対戦を自動で走らせるテスト
tests/net.test.mjs  オンライン対戦の状態同期テスト
scripts/check.mjs   デプロイ前チェック
```
